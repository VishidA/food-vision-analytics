# Project Structure

This repository is organized to support a food image classification system with nutritional analytics.

## Top-level layout

```text
food-vision-analytics/
├── .gitignore
├── .venv/
├── README.md
├── docs/
└── src/
```

## `src/`

The `src/` folder is intended to hold the main implementation code.

- `src/api/` - REST API endpoints, request/response schemas, and service layer code
- `src/data/` - data loading, preprocessing, and dataset preparation logic
- `src/ml/` - model definitions, training, evaluation, and inference utilities

## `docs/`

The `docs/` folder contains project documentation and implementation notes.

Planned topics include:

- architecture overview
- data pipeline description
- model training workflow
- nutritional database design
- API usage examples
